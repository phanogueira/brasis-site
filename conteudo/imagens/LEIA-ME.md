# Imagens do site

Envie aqui as fotos usadas nas análises e projetos (Add file → Upload files).

- Nome do arquivo: só letras minúsculas, números e hífens, sem acentos nem espaços. Exemplo: congresso-nacional.jpg
- Formato: JPG ou WebP, com até 2400 px de largura e, de preferência, menos de 500 KB.
- No texto, use o endereço /assets/img/conteudo/NOME-DO-ARQUIVO. Exemplo: capa: /assets/img/conteudo/congresso-nacional.jpg
- Use só imagens com direito de uso.
