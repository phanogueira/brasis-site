# BRASIS — site institucional

Site de **brasisestrategia.com.br**.

- `site.zip` contém o site pronto (HTML, CSS, imagens e scripts).
- A cada alteração na branch `main`, a automação em `.github/workflows/publicar.yml` descompacta o `site.zip` e publica no GitHub Pages.
- Para atualizar o site: substitua o `site.zip` por uma versão nova (Add file → Upload files).

O código-fonte completo (Eleventy, textos, painel de publicação) está no pacote `BRASIS_site_v2.zip`, guardado fora deste repositório.
